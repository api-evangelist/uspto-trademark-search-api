# USPTO Trademark Search API -- removed from the catalog

This repository used to profile a RapidAPI marketplace listing (rapidapi.com/pentium10/api/uspto-trademark,
served from uspto-trademark.p.rapidapi.com) under the name "USPTO Trademark Search API".

It was removed on 2026-09-23 as a catalog-hygiene decision by API Evangelist (roadmap#621). Nobody asked.
The listing is a third-party wrapper over United States Patent and Trademark Office data, not the USPTO's own
API, and a marketplace listing is not a provider. The USPTO's own record is
[uspto-gov](https://github.com/api-evangelist/uspto-gov).

The slug is on the delisting registry (api-search/network/_data/delisted.yml), so harvests will not re-add it.
